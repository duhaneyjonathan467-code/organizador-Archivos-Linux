# Organizador de Archivos para Linux 🐧

Herramienta gráfica creada en Python para organizar automáticamente los archivos de cualquier carpeta en Linux.

## 🛠️ ¿Qué hace?
Ordena los archivos por categorías (Imágenes, Documentos, Videos, Música, etc.) basándose en un archivo de configuración (`config.json`). Evita sobrescribir archivos existentes agregando un número al final.

## 🚀 Instalación
1. Descarga o clona este repositorio.
2. Abre una terminal en la carpeta del proyecto.
3. Dale permisos de ejecución al instalador y ejecútalo:
   ```bash
   chmod +x instalar.sh
   ./instalar.sh
